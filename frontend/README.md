# EduStream — frontend

Next.js (App Router) + TypeScript + Tailwind CSS + shadcn/ui, consumindo a API em `../backend`.

Ver o [README na raiz do repositório](../README.md) para descrição do projeto, arquitetura e instruções de setup (backend + frontend juntos).

## Comandos

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm run lint
```
